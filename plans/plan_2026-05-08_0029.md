## Fields that ARE live but have sub-fields using random values

Even within the "live" endpoints, some individual fields are faked:

| Endpoint | Fake sub-fields |
|---|---|
| **Bonds** (`sampleBonds`) | `amount` — uses `Math.random()` instead of actual bond amount from DB |
| **LOA** (`sampleLOAData`) | `used` — calculates randomly as 30-70% of aggregate instead of actual usage |
| **Agencies/Premium AR** (`samplePremiumAR`) | `current`, `d1_30`, `d31_60`, `d61_90`, `d90plus`, `invoices` — all random. No real aging data from DB |
| **Premium AR Detail** (`samplePremiumARDetail`) | Entire account-level breakdown is synthetic (random assignment of accounts to agencies) |
| **Premium AR Bonds** (`samplePremiumARBonds`) | Bond-level AR aging is random; premium amounts are random |
