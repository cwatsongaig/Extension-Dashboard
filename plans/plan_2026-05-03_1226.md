## Context

I traced every data array and every consuming function/view in the app. The core problem is that **multiple data arrays were authored at different times with different assumed reference dates**, and the rendering logic uses **inconsistent filters** across dashboard KPIs, detail pages, sidebar badges, action items, and daily briefing.

### Key Findings

**1. Two disconnected "Account Review" data arrays:**
- `sampleARRs` (12 items, multi-account) → feeds dashboard KPI, dashboard ARR list, action items
- `sampleAccountReviews` (7 items, R.J. Corman only) → feeds Account Review detail page table
- KPI says "8 Due/Overdue" but clicking navigates to a page showing 7 historical reviews for one account

**2. LOA dates designed for wrong reference date:**
- `sampleLOAData` comment says "Today's reference: 04/30/2026" but demo date is April 15, 2024
- With April 2024 date, ALL LOAs (including ones marked "Expired") appear Active since their expDates are all after 2024
- Zero LOAs fall in the "expiring within 30 days" window, so that KPI always shows 0
- Exposure gauge includes expired LOAs in its totals

**3. Phantom accounts in `sampleARRs`:**
- 5 accounts (Skanska, Walsh, Flatiron, Manhattan Construction, Sundt) exist ONLY in `sampleARRs` — not in `sampleMyAccounts`, `sampleBonds`, `sampleLOAData`, or anywhere else
- Clicking these accounts from the dashboard leads to empty/missing data everywhere

**4. Account name mismatch:**
- `sampleARRs` says "Brasfield & Gorrie" (no LLC)
- Every other array says "Brasfield & Gorrie LLC"
- This breaks cross-array lookups (account context, action items)

**5. Grade inconsistencies:**
- Granite Construction: grade 'B' in `sampleARRs`, grade 'C+' in `sampleMyAccounts`

**6. Bond request filter inconsistencies (3 different "pending" definitions):**
- KPI card: `Awaiting Approval + UW Review`, current user only → shows 4
- Sidebar badge: `Awaiting Approval` only, ALL users → shows 3
- Action items: `Awaiting Approval` only, current user → shows 3
- Detail page: no user filter at all — shows everyone's requests
- KPI click navigates to "all" tab instead of filtered pending view

**7. `sampleLOAs` vs `sampleLOAData` — two LOA arrays with different dates, used in different views
