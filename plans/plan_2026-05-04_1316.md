## Context

The Account Snapshot widget needs to assemble data from 4 sources for a searched account:
1. **WOH** from `sampleWIPSchedules` (most recent `contractPrice - billedToDate` or similar)
2. **Financial metrics** from `realRedFlagData[branch]` — has `netQuick`, `netWorth`, `netCash`, `debtEquity` per account
3. **Bonds written since last WOH** — filter `sampleBonds` by `effectiveDate > most recent WIP date`
4. **Open bids** — filter `sampleBidLog` where status is 'Approved Bid', 'Pending Bid', or contains 'Low'

The search will filter `sampleMyAccounts` (already scoped to the user's branch). The snapshot displays in a card format below the search box.

### Data availability per source:
- **WOH**: `sampleWIPSchedules` is synthetic with one entry. The `contractPrice` field gives total WOH. For real data, WOH comes from the `billedToDate` minus `costToDate` or similar — but since WIP is synthetic, I'll use the WIP schedule's `contractPrice` as WOH value and its `date` as the WOH reference date.
- **Financial metrics**: `realRedFlagData[branch]` has per-account entries with `netQuick`, `netWorth`, `netCash`, `debtEquity`, `financialStatement` (date). Perfect.
- **Bonds**: `sampleBonds` has `effectiveDate` — filter where effective > WOH date.
- **Bids**: `sampleBidLog` has `status` — filter for 'Approved Bid', 'Pending Bid', or where `bidResult === 'Low'`.

## Implementation Steps

### Step 1: Add `account-snapshot` to DASHBOARD_DEFAULTS panels
Add it as a new standard panel with `visible: true`.

### Step 2: Register `account-snapshot` widget in WIDGET_REGISTRY
The widget renders:
- A search input box
- A results area that shows matching accounts
- When an account is selected, a snapshot card with:
  - **Account header**: name, grade, branch
  - **WOH section**: most recent WOH value and date
  - **Financial Metrics**: Net Quick, Net Worth, Net Cash, D:E — from the most recent financial statement
  - **Bonds Since WOH**: count and list of bonds with effective date after WOH date
  - **Open Bids**: count and list of bids with qualifying status

### Step 3: Implement `searchAccountSnapshot(query)` function
- Filters `sampleMyAccounts` by name (case-insensitive substring match)
- Shows max 5 results in a dropdown
- On click, calls `showAccountSnapshot(accountName)`

### Step 4: Implement `showAccountSnapshot(accountName)` function
Assembles the snapshot from all 4 data sources:
1. Find account in `sampleMyAccounts` for grade/branch
2. Find financial metrics in `realRedFlagData[branch]` matching account name
3. Get most recent WOH date from `sampleWIPSchedules[0].date`, WOH value from `contractPrice`
4. Filter `sampleBonds` where `principal === accountName` and `effectiveDate > wohDate`
5. Filter `sampleBidLog` where status includes 'Approved', 'Pending', or bidResult is 'Low'
6. Render the snapshot card
